# Landing page

The single-section site at **[liaison-rho.vercel.app](https://liaison-rho.vercel.app)**.

One static HTML file with inline CSS and no build step, no framework, and no third-party requests —
the Content-Security-Policy in `vercel.json` is `default-src 'none'`, which a page with an analytics
script or a webfont could not satisfy. Design tokens are copied from `src/client/styles.css` so the
site and the product read as one thing.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page. Inline styles, inline SVG icons, no external assets. |
| `liaison-demo.gif` | Copy of `docs/media/liaison-demo.gif`, served from the same origin. |
| `liaison-still.png` | Static frame shown instead of the animation under `prefers-reduced-motion`. |
| `vercel.json` | Security headers and immutable caching for the images. |

## Updating

Regenerate the animation first if the UI changed, then copy both assets across:

```bash
npm run demo:capture      # writes .demo-frames/, prints the ffmpeg command
cp docs/media/liaison-demo.gif site/liaison-demo.gif
```

Deploy:

```bash
npx vercel deploy --prod --cwd site
```

The production aliases are `liaison-rho.vercel.app` and `liaison-kaushika05s-projects.vercel.app`.
`site/.vercel/` and `site/.env.local` are generated by the CLI and are gitignored.
